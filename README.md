# MUC 成绩提醒助手

面向 Windows 的中央民族大学本科生成绩提醒工具。程序通过可见的 Edge/Chrome 浏览器完成统一身份认证，进入本科生教务系统并检查“本学期成绩”。

## 功能

- 每次随机等待 50–70 秒检查成绩。
- 正式登录后首次读取并播报当前已有成绩。
- 后续只显示和播报本次新出的课程成绩。
- 使用全屏凤凰视频、闪耀文字和 Windows 中文语音提醒。
- `测试凤凰提醒.cmd` 只使用随机虚构数据，不读取真实成绩。
- 密码与成绩不会写入磁盘；成绩基线仅存在于当前进程内存中。

## 环境要求

- Windows 10/11
- Node.js 18 或更高版本
- Microsoft Edge 或 Google Chrome
- Windows 中文语音（通常系统已自带 Microsoft Huihui）

## 使用

1. 下载或克隆仓库。
2. 双击 `启动查分.cmd`。
3. 首次运行会安装 `playwright-core`。
4. 在命令窗口输入统一身份认证用户名和密码。
5. 如遇验证码或身份确认，请在浏览器中手动完成。

测试提醒可直接双击 `测试凤凰提醒.cmd`。详细配置与故障排查见 [使用说明.md](使用说明.md)。

## 隐私设计

- 电脑端密码仅通过当前查分进程环境变量传入，不保存到配置或日志。安卓端可选凭据保险箱使用 Android Keystore 加密且禁止备份。
- 成绩仅保存在 Node.js 进程内存，程序退出即清除。
- `.browser-profile/` 保存本机登录会话，但已被 Git 忽略，绝不能提交或分享。
- 运行日志、依赖目录、临时文件和旧版成绩状态文件均已加入 `.gitignore`。
- 提交代码前可运行 `git status --ignored`，确认浏览器配置保持 ignored。

## 配置

编辑 `config.json` 可调整随机检查间隔、语速、播报次数和凤凰视频文件名。
